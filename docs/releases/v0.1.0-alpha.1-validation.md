Catalogue totals are read from the compiled simulation: **107 goods, 146 gear definitions, 40 processing recipes, 90 structure definitions, 106 techniques and 17 powers**. These counts describe definitions, not completed late-game loops.

The five-year smoke run completed in about 3.1 seconds with roughly 160 MB reported peak memory. This short run started with 150 people. It is not a large-population benchmark, minimum specification or long-term balance result.

The settlement capture uses the existing `--demo village` fixture, which grants techniques and resources before advancing two years. It verifies rendering and packaging, not natural progression to those technologies in two years.

The development-engine screenshot path reports outstanding rendering/font resource warnings during shutdown. The tested release capture completed without those log errors. Full lifetime resource cleanup, long sessions, very large populations, other GPUs, other platforms, real-model throughput and the complete advanced economy remain unverified.

The ZIP has a sorted file list and fixed entry timestamps. Its published checksum is in the release's `SHA256SUMS.txt`; reproducibility of the native/managed compiler output across machines is not claimed.
