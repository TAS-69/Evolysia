# 0.2.0-alpha.1 validation

Checks run on 2026-11-01 on Windows 11 x64 with Godot 4.7.2 (.NET), before publishing `Evolysia-0.2.0-alpha.1-windows-x64.zip`.

## Simulation

- `dotnet test sim/Evolysia.Sim.slnx -c Release`: **102 passed, 0 failed** (37 min). This includes:
  - persistence and save continuity;
  - cognition plan validation;
  - discovery, covering hidden keys for all 106 techniques, experiment validation, discovery, dead ends, work lore and rules-only worlds keeping no lore;
  - identical histories across 1, 4 and 16 threads, for rules-only worlds and for model worlds with lore and experiments.
- After the final hint wording changes, the discovery, cognition and persistence groups were rerun: 22 passed.

## Live model

Local llama-server (lab profile `lite`), runner with a required model, 160 × 80 world, one band of 25.

| run | days | plans accepted / rejected | outcome |
|---|---|---|---|
| seed 42 | 120 | 9 / 2 | survived (22 alive); clues and dead ends recorded; no discovery yet |
| seed 7 (before the tradition fix) | 240 | 11–12 / 1–2 | **starved**: the council read "gather" as gathering food |
| seed 7 (released build) | 240 | 16 / 3 | **all 25 alive**; discovered cooking (day 19, after the hint "it seemed to want meat") and grinding (day 122) |

Rejected plans were invalid generated room layouts, which were corrected on retry. The starvation run led to two fixes: traditions now name the work they describe, and the model sees materials work as `collect_materials`, with work lore stating whether a day's haul can be eaten.

## Assets and package

- `python tools/assetgen/validate.py`: PASS, zero errors; 3,614 assets, 356 colours, 161 slots, 70 nature rows.
- `python tools/release/package.py`: export succeeded. The package verified as self-contained Windows x64 with 3,614 byte-identical asset entries and no local-only files. Archive 88,560,485 bytes, SHA-256 `7b95d076b07d3cfa9329a3e65d3bf33503add3982a954279321eae6208e5a8e1`.
- The archive was extracted to a clean folder and `Evolysia.exe -- --setup` was launched. The new-world screen rendered, the model handshake reported ready, Begin was enabled, and the log had no errors.

## Not covered

Long campaigns (years) under the model, late-game discovery chains, large populations under the model, other platforms and GPUs, and endpoints other than the local llama-server.
