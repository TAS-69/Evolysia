# Evolysia 0.2.0 development build

Development build of the generative civilisation simulation. This is not a published alpha release. Saves and behaviour can change between development revisions.

A compatible running model is required. From a source checkout, install Python 3.11+ and start the local service with `python tools/llm_lab/lab.py bootstrap --helper off --embed off`. First use downloads runtime components and model weights. Exported Windows builds include .NET, but not Python, model weights or server binaries. Keep the complete extracted folder together.

Councils now generate work plans, individual goals and reflections, research, construction, sharing, diplomacy and leadership decisions. They can propose named room layouts, viable community divisions, reciprocal unions and physical cargo jobs. All effects validate against world rules; time waits through outages and invalid replies.

F5 quick-saves; F9 opens named and automatic slots. Three autosaves rotate every thirty simulated days by default. The World menu includes display/accessibility settings, model connection settings and an expanded appearance editor. F follows the selected person or band. Clothing still needs manufacture. Portraits show inherited features, emotion and scars. Specialist interiors contain independently owned fixtures and physical stock.

Ordered manufacturing, fuel/solar power, battery storage, refrigeration, staffed care/teaching/research/worship/governance/guards, roads, cliffs, terrain shaping and basic possession are connected. Complete magic/space gameplay, future industry chains, universal physical logistics, deeper laws/markets, traffic clearance, final interface/effect assets, culture glyphs and broader platform verification remain unfinished. Model latency can dominate speed. Development saves are not guaranteed to remain compatible.

Read [Development status](https://github.com/TAS-69/Evolysia/blob/main/docs/DEVELOPMENT.md) and the [wiki](https://github.com/TAS-69/Evolysia/wiki) for current scope. Code/documentation use MIT; original artwork and branding remain separately reserved. Dependency and engine notices are included with exported builds.
