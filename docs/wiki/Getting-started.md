# Getting started

Download the Windows x64 archive from [Releases](https://github.com/TAS-69/Evolysia/releases), extract it completely and run `Evolysia.exe`. Keep `assets`, the managed data folder and `Evolysia.pck` alongside the executable. No editor, Python or separately installed .NET runtime is required for the packaged game.

Use a Vulkan-capable GPU. This alpha has been checked on Windows; Linux, macOS, integrated GPUs and alternative rendering backends have not been release-tested.

The opening screen lets you choose a numeric seed and a planet:

| Planet | Character |
|---|---|
| Terra | Balanced continents and varied climates |
| Ignis | Hot, dry and volcanic |
| Cryos | Cold, ice-bound and short summers |
| Thalassia | Mostly ocean, with small islands |

Choose one to six peoples. Each starts with its own culture and language, split into two bands. **Scatter at random** chooses suitable land. **Place on the map** lets you place their starting positions; click a marker again to remove it. Placement is adjusted to liveable land by the simulation.

Select **Begin**, zoom towards a band and left-click to inspect it. Space pauses the world, which is useful when reading a particularly complicated family situation.

**New world… replaces the current world after Begin. There is no save/load yet.** The Back button returns to an existing session without replacing it.

The same seed starts the same ordinary simulation. Later player actions and accepted local-model choices affect its history. Model-generated text itself is not guaranteed to repeat.
