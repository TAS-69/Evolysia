# Changelog

## 0.1.0-alpha.1 — 2026-10-31

Initial playable alpha.

- Seeded planets, world setup and one to six starting peoples.
- Autonomous daily life, inheritance, psychology, culture, technology, settlement, production and sea migration.
- Seventeen god powers, inspection, chronicle, map overlays and adjustable time.
- Modular people and buildings, regional materials, visible stores and multiple artwork densities.
- Optional local voices and validated pivotal choices, with instinct fallback.
- Official Evolysia branding in the menu, boot splash and Windows package.
- README, wiki, source build instructions and explicit alpha limitations.
- MIT code licence, reserved original artwork rights and bundled third-party notices.

Save/load, complete cargo logistics, the outfit editor and full late-game content remain unfinished. See [release notes](docs/releases/v0.1.0-alpha.1.md).
